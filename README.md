# 微信防撤回 for macOS


一个面向普通用户的 macOS 微信增强工具。当前版本通过原生动态注入提供防撤回、自定义提示、消息提醒等功能，**不修改原微信程序的任何文件，也不重签原微信 App；运行前需要关闭 macOS 的 SIP（系统完整性保护）**。

> **本机当前微信 4.2.0 / 270353（兼容旧 268602）：请使用首页「原生动态注入」。** 已接入其他动态功能，原微信安装包保持不变。[查看当前版本使用说明](#native-injection)。下文的历史静态安装流程不适用于这份本机核心库。

**[上游发布页（历史静态版本）](https://github.com/fzlzjerry/wechat-antirecall/releases)** · [遇到问题](#遇到问题) · [进阶用法](#进阶用户命令行)

> **当前版本使用前先看**
>
> - 支持 **Apple Silicon（M 系列）Mac**，当前原生注入适配构建 **268602（微信 4.1.9）** 和 **270353（微信 4.2.0）**。
> - **运行需要先关闭 SIP**。输入管理员密码不能代替关闭 SIP；本工具不会自动修改 SIP 设置。
> - **不修改原微信 App 内的任何文件**，包括主程序、`wechat.dylib`、资源和签名。插件副本与配置保存在 App 包外，Hook 只作用于微信进程内存。
> - 微信退出后，本次注入失效。重新打开微信后，需要再次点击「注入微信 · 开启防撤回」。
> - 更新微信或运行组件后，请完全退出微信和旧 GUI，再使用新版重新注入。关闭 SIP 是前提，不保证所有系统环境都能完成注入；失败时查看界面的具体错误。
> - 「微信多开」会创建独立副本并修改、重签副本；**原微信仍保持不变**。
> - 下文保留的静态 `install` / 补丁安装说明属于历史方式，会修改目标 App，不能与当前动态注入流程混用。

## 当前版本使用方法

### 1. 关闭 SIP

先在 macOS 恢复环境中关闭 **SIP（系统完整性保护）**，然后正常重启进入系统。当前原生注入模式需要此条件，单独授予管理员权限不够。

### 2. 构建并打开 GUI

在项目目录运行：

```sh
bash Scripts/make-app.sh
open dist/WeChatAntiRecall.app
```

这里只构建并签名本工具，不修改或重签原微信 App。

### 3. 选择微信并注入

1. 在首页选择要使用的微信 App，确认版本和构建号受支持。
2. 点击 **「注入微信 · 开启防撤回」**。微信未运行时，GUI 会先以普通用户身份打开微信，再请求管理员授权用于注入。
3. 根据提示输入 macOS 管理员密码，等待界面确认注入成功。
4. 在首页和左侧功能页设置静默模式、自定义提示、撤回记录、关键词提醒、窗口隐私或红包模式。提醒、记录和自动红包等功能需要主动开启。

### 4. 停用与重新启用

完全退出微信即可停用本次注入，无需恢复微信程序文件。偏好设置会保留；下次启动微信后，需要再次从 GUI 注入。


### 需要关闭 SIP 吗？

需要。工具不修改「应用程序」中的微信，动态注入到微信。

### 支持 Intel Mac 吗？

当前发布的 GUI 只支持 Apple Silicon（M 系列）Mac。

原生注入的使用顺序：

1. 完全退出微信并重新打开，退出旧版防撤回 GUI，再打开新版 GUI，点击首页注入。
2. 首页可切换静默模式、屏蔽更新；左侧页面可设置提示、撤回记录、关键词、窗口隐私及红包模式。自动红包、提醒和记录默认关闭，不会因注入而自动开启。
3. 内容缓存只覆盖新版插件注入后收到的消息。动态功能状态会核对目标 PID、进程启动时间和加载组件；微信退出后不会继续显示为已注入。
4. 多开通过「微信多开」创建独立副本，保留原微信不变，但会修改并重签副本的标识。随后在首页选择该副本并注入。不是对同一安装路径强开多个进程。
5. 要停用动态功能，退出微信即可；设置会保留。屏蔽更新仅控制后续检查/自动下载，不撤销已经开始的更新任务。关闭屏蔽时恢复注入时保存的 Sparkle 自动检查/下载开关。

地址和 ABI 的静态核对记录见 [268602 功能适配](Docs/native-268602.md)。按用户要求未运行测试或真实消息、红包操作；编译通过不等于业务实测通过。

270353 更新后的本地逆向记录见 [4.2.0 适配](Docs/native-270353.md)。本机实际版本号为 4.2.0，不要套用旧版本地址。
